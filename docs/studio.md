# 本地流程工作台

```powershell
.\.venv\Scripts\python -m browser_skill_agent studio
```

打开中文网页工作台，不需要 Node、前端构建或单独启动服务器。界面运行在由 Playwright 打开的 Edge 中；本地页面通过受限绑定调用 Python，只接受工作台主页面发起的命令，任务网页不能操作流程库。

## 用户操作

- **管理流程**：首次打开导入项目 `skills/`；旧版 `data/generated/` 中的流程会兼容迁入 skills。用户看到中文名称、用途、默认参数和状态，不显示内部 Skill 文件。可以搜索、筛选、重命名、修改默认参数或删除流程。
- **直接运行**：选择流程后自动填入录制的演示参数，可以修改本次参数。勾选“流程结束后自动关闭浏览器”则结束即关闭；默认保留结果页面，可在工作台关闭。默认按固定步骤运行；勾选“启用 LLM 运行”后，模型观察页面并分阶段规划。每次打开运行面板时该选项默认关闭。执行方式与授权独立，仍可选择人工确认（默认）、AI 审核或全部允许。只有关键操作触发审核，普通搜索、填写和筛选直接执行；人工确认在网页中完成。
- **对话准备**：输入要求，模型从已有流程中选择并填入参数，保留最近的简短对话上下文。点击“检查参数并运行”后确认执行，不让模型直接执行自由工具操作。缺少默认参数的历史流程需补齐参数。
- **对话修改**：在右侧说明流程名称及修改要求，例如“将查询流程的关键词参数去掉，固定为人工智能”。助手先匹配目标，再读取完整流程生成修改方案；聊天中展示修改说明、前后参数及可展开的操作步骤。点击“确认修改”才保存，取消不改变原流程。移除参数时同步调整步骤、阶段及引用；没有可用固定值时会询问。保存后撤销旧的验证状态，并自动后台验证与有限修复；使用全部授权，两种模式都通过后标为“双模式验证通过”。已有任务未结束或流程在确认前被其他操作改动时，不覆盖修改。每次新需求会使上一份待确认方案失效。
- **录制新流程**：输入名称和网址后打开独立浏览器，正常操作。关闭这个浏览器即结束录制，随后出现选填的生成指导窗口。可以补充流程名称、用途与完成条件、参数选择建议，也可点击“直接生成”。信息越准确，越有助于生成贴合需求的流程；不填写不会阻止生成。工作台始终保留，也可点击“结束并生成”，先保存记录和正在进行的下载，再关闭录制窗口并进入相同选填步骤。选填窗口关闭后可从任务状态栏重新打开；关闭整个工作台不会自动提交这些说明，原始录制仍保留。
- **重新录制**：工作台提供确认，旧记录标为已放弃，返回起始页面重新录制。保留同一录制会话，但不撤销网站上已发生的提交或上传。

录制和生成可能耗时，工作台展示当前状态和模型生成进度。自动生成、对话选择使用 `.env` 中的模型服务，相关文字与录制摘要会发送到该服务；启用 LLM 运行会调用规划模型并发送页面信息；即使不启用，选择 AI 授权后遇到关键操作也会调用审核模型。模型用量累计在任务结果中。

## 状态与限制

每次实际启动运行、录制或重新生成任务时，右侧对话切换到新任务，显示启动提示和最终结果，读取内容可展开查看；同时清空上一任务对话上下文与日志。任务结束后的首次新需求也会清空旧结果显示，同一次准备过程中的连续参数修改保留上下文。

左侧底部只显示紧凑状态栏和操作按钮。“展开运行日志”在页面内展开独立滚动区域，不弹出遮罩、不覆盖主界面。日志包括执行步骤、等待结果、授权和错误，默认折叠，刷新不会自动收起。本次任务内存保留最近 500 条日志，每条最多 4000 字符；关闭工作台后不保留此日志面板历史。

新生成或导入的流程标为“待验证”。脚本完成后标为“运行通过”，仅表示本次步骤及等待条件通过，不证明业务结果或所有参数都有效。失败标为“需要调整”；后台验证可有限修复流程，详见[验证与修复](sandbox.md)。

无法制定验收条件时会先执行固定步骤试运行；完成后保留“待验证”，不会标记双模式验证通过。

创建后默认自动验证，也可以在录制面板关闭该选项。保存默认参数或流程定义、确认聊天修改后自动重新验证；仅改显示名称不重跑。编辑面板也提供手动“后台验证与修复”入口。生成后的自动验证默认采用 headless 无窗口模式，使用全部授权并启用上传下载；文件调用额度按修复版本独立计算。不改变普通运行授权设置。

关闭录制浏览器后，只能使用已送达并落盘的事件。关闭瞬间未发送的状态不能补采，正在下载的文件也可能被浏览器取消；有文件操作时建议等完成，或用工作台“结束并生成”。网页原生弹窗由工作台确认接受/取消，当前工作台不提供 prompt 文本输入。

同一时间只运行一个浏览器任务；保留最终浏览器时，需要先关闭它再开始新任务。关闭工作台会结束受管浏览器；未正常结束的录制不会自动生成。工作台是本地单用户应用，不是可远程访问的多用户服务。

## 存储与结构

`data/flows/index.json` 保存中文名称、默认参数、状态和最近结果；`skill_path` 指向项目 `skills/<目录>/SKILL.md`，运行、聊天编辑与验证通过后的修复都使用这一份定义。默认参数同步到同目录 `example_params.json`。旧版 data/flows 中仍在工作台的流程会自动迁移，以其最新定义为准；旧文件仅作备份，不再执行。已删除的流程不会恢复。删除流程会同时删除对应 skills 目录、旧版流程备份及有明确关联的原始录制、历史生成目录和验证目录（含验证用文件副本）。其他流程共用的记录留到最后一个关联流程删除时清理。不会按参数路径删除用户上传原件、日常下载文件或共享浏览器 profile。无法确定归属的旧验证目录保留。

- `studio/editing.py`：对话修改提示与现有工具契约校验。
- `studio/store.py`：流程目录与默认参数。
- `studio/schedules.py`：单次计划持久化、配置校验与状态恢复。
- `studio/app.py`：工作台、独立录制窗口、生成、对话与执行桥接。
- `studio/index.html`、`style.css`、`app.js`：无框架的本地网页界面。

```powershell
.\.venv\Scripts\python tests/studio.py
```

测试使用真实本地 Edge，模型响应使用测试替身，覆盖参数、改名、删除、对话准备、授权、重录、关闭录制触发生成和运行窗口生命周期。此测试不等同于线上流程验证。

对话修改本地验证（模型使用测试响应）：`python tests/studio_editing.py`。覆盖取消、确认保存、参数固定后的脚本重放、过期方案与无效引用。

需要登录的流程可生成 login 配置和账号/密码参数；密码仅在本次会话内使用，自动验证在缺少密码时暂停。后台遇到扫码或验证码显示浏览器，人工完成后继续。详见[登录与接管](login.md)。

录制完成后的补充说明弹窗和生成进度栏提供“取消生成并删除记录”。取消后删除本次录制目录，不添加流程、不启动验证；已经发生的网站操作不会撤销。生成中会先显示“正在取消”，在模型流下一次返回或请求结束后清理，已发出的模型请求无法保证停止计费。

## 计划与定时

左侧「个人工作台 → 计划与定时」可创建单次计划。选择流程后先填写运行参数，再设置执行时间、授权模式、是否启用 LLM、后台运行和结束后关闭浏览器。LLM 默认关闭，授权默认人工确认，定时任务默认结束后关闭浏览器；取消「保存后启用计划」可先保存为暂停状态。修改计划并启用即可重新安排。

计划保存在 `data/studio/schedules.json`，参数是保存当时的独立副本。密码不落盘，需提前通过流程参数面板填写本次工作台会话密码。流程定义修改后，原计划不会自动执行新定义，需要检查并重新保存；删除流程会取消关联的待执行计划。

当前为本地工作台内定时器：必须保持工作台打开、电脑唤醒。时间使用本机时区显示、UTC 保存。工作台关闭时错过的计划不补跑；异常退出时已触发的计划标记中断，不自动重试。运行任务或保留的任务浏览器占用工作台时，计划等待空闲，超过执行时间 5 分钟后标记过期。人工授权及登录仍需用户确认，选择全部允许不会绕过网站登录。

计划列表显示状态、执行选项、参数和结果摘要。当前计划的「查看运行日志」会返回主界面查看详细日志及右侧对话结果。步骤执行完成仍不等于独立业务验收通过。

后台运行使用最小化的有界面浏览器，不再将窗口移出屏幕。运行中可点击任务栏恢复查看；自动切换同窗口标签页不会再次隐藏用户已恢复的窗口。需要人工登录时显示窗口，完成后重新最小化。
