# 本地流程工作台

```powershell
.\.venv\Scripts\python -m browser_skill_agent studio
```

打开中文网页工作台，不需要 Node、前端构建或单独启动服务器。界面运行在由 Playwright 打开的 Edge 中；本地页面通过受限绑定调用 Python，只接受工作台主页面发起的命令，任务网页不能操作流程库。

## 用户操作

- **管理流程**：首次打开导入项目 `skills/` 和已有 `data/generated/` 中的流程。用户看到中文名称、用途、默认参数和状态，不显示内部 Skill 文件。可以搜索、筛选、重命名、修改默认参数或删除流程。
- **直接运行**：选择流程后自动填入录制的演示参数，可以修改本次参数。勾选“流程结束后自动关闭浏览器”则结束即关闭；默认保留结果页面，可在工作台关闭。运行使用脚本模式；可选择人工确认（默认）、AI 审核或全部允许。只有关键操作触发审核，普通搜索、填写和筛选直接执行；人工确认在网页中完成。
- **对话准备**：输入要求，模型从已有流程中选择并填入参数，保留最近的简短对话上下文。点击“检查参数并运行”后确认执行，不让模型直接执行自由工具操作。缺少默认参数的历史流程需补齐参数。
- **录制新流程**：输入名称和网址后打开独立浏览器，正常操作。关闭这个浏览器即结束录制并自动生成流程。工作台始终保留，也可点击“结束并生成”，先保存记录和正在进行的下载，再关闭录制窗口。
- **重新录制**：工作台提供确认，旧记录标为已放弃，返回起始页面重新录制。保留同一录制会话，但不撤销网站上已发生的提交或上传。

录制和生成可能耗时，工作台展示当前状态和模型生成进度。自动生成、对话选择使用 `.env` 中的模型服务，相关文字与录制摘要会发送到该服务；直接运行流程仅在选择 AI 授权且遇到关键操作时调用审核模型。

## 状态与限制

每次实际启动运行、录制或重新生成任务时，右侧对话切换到新任务，显示启动提示和最终结果，读取内容可展开查看；同时清空上一任务对话上下文与日志。任务结束后的首次新需求也会清空旧结果显示，同一次准备过程中的连续参数修改保留上下文。

左侧底部只显示紧凑状态栏和操作按钮。“展开运行日志”在页面内展开独立滚动区域，不弹出遮罩、不覆盖主界面。日志包括执行步骤、等待结果、授权和错误，默认折叠，刷新不会自动收起。本次任务内存保留最近 500 条日志，每条最多 4000 字符；关闭工作台后不保留此日志面板历史。

新生成或导入的流程标为“待验证”。脚本完成后标为“运行通过”，仅表示本次步骤及等待条件通过，不证明业务结果或所有参数都有效。失败标为“需要调整”；当前界面不自动修复流程，也不会将已有的虎牙草稿标为已通过。

关闭录制浏览器后，只能使用已送达并落盘的事件。关闭瞬间未发送的状态不能补采，正在下载的文件也可能被浏览器取消；有文件操作时建议等完成，或用工作台“结束并生成”。网页原生弹窗由工作台确认接受/取消，当前工作台不提供 prompt 文本输入。

同一时间只运行一个浏览器任务；保留最终浏览器时，需要先关闭它再开始新任务。关闭工作台会结束受管浏览器；未正常结束的录制不会自动生成。工作台是本地单用户应用，不是可远程访问的多用户服务。

## 存储与结构

`data/flows/index.json` 保存中文名称、默认参数、状态和最近结果；每个流程有独立内部执行文件副本。修改和删除不改变原始示例、录制或生成产物。删除从流程库移除，保留内部文件用于恢复，不会下次启动重新导入。

- `studio/store.py`：流程目录与默认参数。
- `studio/app.py`：工作台、独立录制窗口、生成、对话与执行桥接。
- `studio/index.html`、`style.css`、`app.js`：无框架的本地网页界面。

