# 用户操作录制

录制器把用户演示保存为本地操作记录，不调用 LLM，不提取参数，不生成或执行 Skill。现有 Skill 执行方式保持不变。

## 启动与使用

在项目根目录执行：

```powershell
.\.venv\Scripts\python -m browser_skill_agent record
```

也可以预填网址：

```powershell
.\.venv\Scripts\python -m browser_skill_agent record --url https://cn.vuejs.org/guide/introduction.html
```

1. 在控制页输入起始网址，点击“开始录制”。浏览器会打开任务页面。
2. 正常操作网页。输入、点击、选择、上传、下载和新标签页自动记录，不需要手动标记阶段或参数。
3. 完成后切回“浏览器操作录制”控制页，点击“结束并保存”。已有下载仍在进行时显示等待状态，完成或失败后保存最终记录。
4. 查看操作数量、页面数量、下载结果和记录目录。“查看最近操作”默认折叠，最多展示最近 30 个动作；完整记录在文件中。

控制页会提示：完整、连贯的演示，减少无关操作和反复尝试，有助于后续生成更准确、稳定的 Skill。正常等待加载、上传和下载即可，不需要加快点击。

首次使用不需要 API 密钥。录制器固定显示浏览器，不提供后台录制模式。支持 HTTP、HTTPS 和 file:// 起始网址；不会附着到用户已经打开的普通 Edge 窗口。

## 重新开始

录制中点击“重新开始”，先显示确认提示：“本次记录将标记为已放弃，并返回起始页面。已在网站完成的上传、提交或购买不会撤销。”用户可选择继续当前录制或确认重新开始。

确认后：

- 旧记录标为 abandoned，保留在原目录，后续生成 Skill 时必须排除该状态。
- 取消旧录制尚未完成的下载，保留已经下载的文件；不混入新记录。
- 关闭旧录制任务标签页，创建新的编号、记录文件和下载目录，回到原始入口。
- 继续使用同一个浏览器上下文，因此 Cookie 和登录会话保留；不还原服务器状态或页面业务数据。

结束后的“开始新的录制”会保留前次 completed 记录，关闭旧任务页并开始新记录。关闭控制页会退出本次录制浏览器；未结束的记录标为 interrupted，已落盘的事件保留。

## 保存内容

```text
data/recordings/<录制编号>/
  session.json       # 状态、时间、页面与框架、下载结果、统计
  events.jsonl       # 按接收顺序追加的原始事件
  actions.json       # 合并后的操作及关联观察，录制期间持续更新

files/recordings/<录制编号>/downloads/
  d1-结果文件名      # 编号前缀避免同名覆盖
  d2-结果文件名
```

data/ 和 files/ 已被 Git 忽略，不应把个人录制内容直接提交。session.json 和 actions.json 使用临时文件替换方式更新，避免读到半个 JSON；events.jsonl 每条事件单独追加。

| 记录 | 内容 |
| --- | --- |
| 用户动作 | 点击、双击、填写、选择、勾选、Enter/Tab/Escape/方向键、文件选择；同一元素连续输入合并为 fill，原始输入事件仍保留 |
| 定位候选 | 标签、role、名称、label、placeholder、ID、测试标识及相关容器；这些是候选，不保证已唯一或稳定 |
| 页面与框架 | 页面编号、URL、标题、新页来源、页面关闭和激活、iframe 编号与父框架关系；支持可注入脚本的跨源 iframe |
| 操作上下文 | 局部文字、页面文字摘录、可见控件的启用、勾选、展开、选中和非敏感输入值；观察不等于成功断言 |
| 上传 | 文件名、大小、类型、修改时间；安全上下文中不超过 16 MiB 的文件尝试计算 SHA-256，只传摘要，不复制上传内容或暴露真实本机路径 |
| 下载 | 开始、保存成功、失败或取消状态，建议名称、实际保存路径、字节数和 SHA-256；文件操作完成不代表业务任务成功 |
| 辅助事件 | 滚动、页面跳转、脚本注入和刷新失败等；滚动先留在原始事件中，不自动转换为执行动作 |

文件选择仅表示文件进入网页控件，不表示服务器已经收到。网站上传完成提示会作为普通页面观察记录，不自动推断成功。

页面观察通过 DOM 变化触发，并每秒补采样控件状态；相同快照不重复保存。文本最多 4,000 字符、控件最多 30 个，超过时标记截断；填写值最多 8,000 字符，标记 value_truncated。合并动作保留最近五份关联观察，原始事件保留全部已记录观察。它不会阻塞用户操作等待“网络完全空闲”，也不保证捕获瞬间闪过的所有状态。

## 登录、隐私与特殊情况

可选复用独立的登录目录：

```powershell
.\.venv\Scripts\python -m browser_skill_agent record --profile-dir data/recording-profile
```

该目录不能与其他进程同时占用。默认会话是临时目录；关闭浏览器后不承诺保留登录。录制器不自动登录，也不会复制用户日常浏览器配置。

密码类型、密码/验证码等已识别敏感输入值遮蔽为 null；常见认证 URL 参数和 URL 用户信息也会遮蔽。不读取 Cookie、请求头或完整网络请求体，不录截图、视频。普通页面正文和普通输入仍会记录，启发式遮蔽无法识别所有站点自定义敏感字段。

网页原生 alert/confirm/prompt 由控制页提示用户处理，记录类型和接受/取消结果；prompt 的输入文本不写入记录。网页自己的 HTML 模态弹窗按普通 DOM 操作记录。Edge 的内部下载中心等浏览器页面不属于录制对象。

结束录制会停止接收后续用户操作，并等待已经捕获的下载事件保存。若点击下载后服务器迟迟没有触发下载事件，应先等待下载开始再结束。画布内部操作、关闭的 Shadow DOM、浏览器设置页面和系统文件对话框内部操作不提供完整录制；上传记录以网页文件输入控件的最终选择结果为准。拖放文件到纯自定义区域而未经过 input[type=file] 的场景尚未覆盖。

## 本地验证

```powershell
.\.venv\Scripts\python tests/recording.py
```

测试使用真实 Edge 和本地 HTTP 网站，不消耗模型 Token。覆盖输入合并、双击、密码遮蔽、动态状态、原生下拉、勾选、跨源 iframe、新标签页、网页弹窗、双文件选择与摘要、同名下载、结束时等待保存、导航后继续捕获、重新开始确认、会话保留和中断状态。设置 RECORDING_HEADED=1 可在可见浏览器中运行；测试结束会关闭测试浏览器。
