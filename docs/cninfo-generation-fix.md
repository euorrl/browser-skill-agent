# 巨潮公告录制生成修复

> 历史验证记录：结论仅适用于文中版本、参数和当时的网站状态。当前功能与命令见[文档索引](README.md)。

2026-10-25，原录制 `20261025-122218-03b72354`，实际目标是贵州茅台 2026 年半年度报告，公告编号 1225475868。

## 根因

- 生成器把完整公告标题降为公司关键词，30 个链接匹配同一个定位。
- 旧脚本在切换新页前等待新页 URL，并硬编码 p2。
- 录制的 DOM 文字“公告下载”不含 CSS 伪元素图标，而无障碍名称含图标，精确名称等待失败。
- 沙箱复用了编辑名称校验，自动修复被与执行无关的显示名称错误阻断。
- PDF 内嵌查看器不应参与登录 DOM 检测。

## 修改

保留完整业务对象身份；增加 click.expect_popup 的先监听、后点击、自动切换能力；DOM 文字候选使用 role/has_text 并标记来源；沙箱执行修复保留原名称并落盘修复响应；登录检测跳过 PDF 和浏览器扩展框架。

## 真实验证

使用配置的真实模型重新生成草稿（1 次请求，13,011 Token），再运行沙箱。首版脚本在下载按钮精确名称处失败，模型根据真实现场自动修复一次。修复后同一版本在独立脚本和 LLM 会话均通过公告详情 URL、下载数量及大小验收。

验证共 7 次模型请求（1 次修复、6 次 LLM 规划），51,450 Token，92.34 秒。LLM 曾遗漏新标签页切换，等待失败后重新观察并恢复，未重复点击公告。

两份下载均为 832,321 字节，PDF 文件头及结束标记存在，SHA-256 相同：`0e10aa26be46b1cf3cd03f06e834c7fb98d5dd0d661b96f8fddd4af7e846a4f6`。未进行 PDF 全文语义核验。

证据：`data/validations/20261025-123313-03970ff6/report.json`；原始测试记录及备份：`.cache/cninfo-fix/`。已将通过版本应用到原工作台流程，保留内部标识和显示名称。

本地回归：generation、sandbox（修复响应省略显示名）、stage_navigation、browser_tools、recording、popup_click、login（8 项）通过。此验证不代表任意公司、年份或翻页查询均已通过。


## 第二次录制复现与生成链路修正

最新录制：`20261025-125147-39817f18`。用户要求只暴露股票关键词参数，演示值为“茅台”。失败报告 `20261025-125313-77296379` 中，第一轮同时匹配全文和摘要；第二轮文件已保存，但被按钮恢复等待挡住；第三轮下载文件仅 9,256 字节，实际为 HTML。之前通过一个实例不足以证明重新生成稳定。

本次增加录制证据驱动的定位确定步骤，将已知完整 DOM 文字转换成 has_text_exact，并写入 LLM 正文约束；对唯一已录制候选补齐裸 role 可见性等待。禁止生成时通过 nth 猜第一个匹配项；拒绝截短已知身份与用下载按钮恢复证明文件完成。下载工具和独立验收均检查 PDF 文件头，错误 HTML 不再作为成功。后台窗口管理忽略 Edge 下载中心等无独立窗口的内部页面。

通过实际 Studio.generate_flow → Store.add → Studio.validate 路径连续复测，保留每轮记录于 `.cache/cninfo-generation-v2` 到 `v5`，中间失败和修复没有覆盖。最终 v5 重新调用真实模型生成（无手写替换动作），格式纠正 0 次，沙箱修复 0 次，初版脚本和 LLM 都通过。唯一参数仍为 stock_keyword=茅台，目标公告固定为录制的半年度报告，不声称任意关键词都能找到其他公司的报告。

最终生成 1 次模型请求、13,189 Token；验证 6 次模型请求、38,669 Token，验证耗时 40.5 秒。两份文件均为 832,321 字节，SHA-256 与前次真实 PDF 相同。固定验收、原始定义、执行轨迹见 `data/validations/20261025-130629-90de0226/report.json`。已采用到工作台最新的“年度报表下载”流程，只保留原内部标识和显示名。

本地回归：generation_identity（6 项）、generation（12 项）、sandbox_contract、browser_display、browser_tools、recording、sandbox、studio_generation_cancel、llm_batches 通过。未对任意其他网站或其他参数值作成功保证。
